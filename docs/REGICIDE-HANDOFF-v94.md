## What the game is
Browser 50v50 third-person medieval war game, nutcracker-soldier aesthetic. The player is ONE unit among ~110 AI (plus 36 neutral creeps). AoE2-style shared team economy, six ages (Stone → Bronze → Iron → Classical → Medieval → Enlightenment), win by regicide (kill the enemy king, +500 pts). Flow: NAME SCREEN → main menu (Solo / Host / Join / How-to-Play) over a frozen cinematic world. Three.js r128 via plain `<script>` tags, NO bundler/modules. Host-authoritative P2P over PeerJS/WebRTC. **NET.PROTO=18** — bump it whenever wire format, world layout, movement rules, placement rules, or balance stats change (all desync mixed versions). Pure-UI changes don't need a bump but keep both machines on the same build anyway.

### Smoketest gotchas (each of these bit us — READ before editing tests)
- `__G` export string ~line 35-42 lists exported globals; the main destructure below it does NOT include everything (e.g. `directors` is destructured LATER in the file — referencing it early throws TDZ "before initialization"; use `global.__G.directors`). The export string accepts arrow entries (`getT:()=>T`, `setAIDiff:v=>{aiDifficulty=v;}`).
- The MENU gate: sim frozen at load — smoketest calls `NET.uiSolo()` before the first tick loop.
- Possession reassigns `player` — use `units.find(u=>u.isPlayer)` in guest-era tests.
- Guest-mode stretches: wrap host-only calls with `NET.mode="host"; ...; NET.mode="guest"` / restore `"solo"`.
- **gameOver mutes ALL dealDamage/damageBuilding.** Staged fights and the campaign itself can kill a king (v94 personalities made campaign regicide COMMON — rush!). Every post-campaign section that stages combat opens with `global.__G.setGameOver(false);` (v94/v87/levy/camps/charge/rebalance/scoring/priest sections all carry one). Keep the pattern for new sections — a missing guard once failed 25 tests at "0 damage".
- **Never assert team-stock deltas across live ticks** — directors spend and economy drips in the same tick. Direct calls to `economyTick(1.0)` (flush once, then measure exactly one step) are fine. awardPts multiplies by the Bounty buff — ×1.0 at zero stacks, so exact-score asserts still hold with `u.remote="x"` units.
- Buff tests must ISOLATE buffs (one id at a time; allies >12u from any Captain's Banner bearer; stub `Math.random=()=>0` for dodge/crit and restore). `u.remote="x"` makes a unit "human" for quests/buffs/awardPts.
- applyLOD tests: position the PLAYER, not the camera, and let the LERP arrive.
- `makeUnit` units lack `u.spread`; guard `(u.spread||0)`. Test units: `bot:{role:"citizen"}` for bot hooks, or `bot:null` + big hp to stand inert.
- Real three@0.128.0 loads; `document` stubbed (CanvasTexture-safe); stub elements cache by id (settable `.value`, `.innerHTML`). `grep -c` exits 1 on 0 matches. `localStorage` is undefined in node — game code try/catches it.
- Campaign end-state varies — make post-campaign tests deterministic (call managers directly, force `st.respawnAt=-1`, insta-build pending sites, etc.).
- **When adding a regression test, VERIFY IT BITES** — and verify the bite actually landed: one board-guard probe "passed" with the guard removed because the probed spots were ALREADY refused by TC clearance (vacuous test). The fix pattern: self-calibrate (find ground where placement IS legal, add the thing, watch the same spot flip).
- Fixed-coordinate `validFor` probes can flip when placement rules change (the 2.2 gap moved a five-markets probe; personalities sprawl towns onto old marks). Hardened asserts: charge-hold is ≥2/3 within 16; AI-blacksmith counts forges EVER BUILT (they get razed by late ages); camp packs tolerate campaign attrition (strict 4-5 only on a forced fresh wave).

## Current game systems (quick reference)
- **Questing (v87-v93)**: Town Board by each TC (E). 25 quests, ev-driven counters, hard ones pay 2 levels/2 XP, +25 score/xp. One active; double-E rerolls (60s cd). Max level 20. Level shows on tags/scoreboard for everyone. **Blacksmith** (Iron, 100w, 1/team, AI auto-builds): E lays THREE random non-maxed buffs on the table, choose ONE per XP; **the trio stands until chosen** (no fishing). 21 buffs, ×3 stack cap. **Death wipes level, XP, quest, buffs, and the standing offer.** Bots never quest. TAB shows full quest text + all active buff descriptions.
- **Rally/Charge**: G rallies your 5 NEAREST soldiers (Bannerman +1/stack, max 8); G again recalls; F charges the rallied line (holds far ground).
- **Menus (v92)**: name screen (localStorage) → menu. HOST: PvP/Co-Op (co-op admits all joiners BLUE), Public/Private+password (private = unlisted + password on hello). JOIN: auto-opens the hall browser + code/password fields for private halls.

Human teams always run "normal" incl. the press-T-first courtesy buffer.
