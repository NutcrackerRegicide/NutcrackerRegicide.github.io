## What the game is
Browser 50v50 third-person medieval war game, nutcracker-soldier aesthetic. The player is ONE unit among ~110 AI (plus 36 neutral creeps). AoE2-style shared team economy, six ages (Stone → Bronze → Iron → Classical → Medieval → Enlightenment), win by regicide (kill the enemy king, +500 pts). Flow: NAME SCREEN → main menu (Solo / Host / Join / How-to-Play) over a frozen cinematic world. Three.js r128 via plain `<script>` tags, NO bundler/modules. Host-authoritative P2P over PeerJS/WebRTC. **NET.PROTO=20** — bump it whenever wire format, world layout, movement rules, placement rules, or balance stats change (all desync mixed versions). Pure-UI changes don't need a bump but keep both machines on the same build anyway.

### Smoketest gotchas (each of these bit us — READ before editing tests)
- **The bundle is STRICT-MODE eval** (`"use strict"` tops 00-data.js): NOTHING attaches to `global` — not even function declarations. EVERY game symbol a test touches must ride the `__G` export string (~line 35-43). It accepts arrow entries (`getT:()=>T`, `shootArrow:(a,b)=>shootArrow(a,b)` — the arrow form keeps the LIVE binding for monkeypatched functions). The main destructure below it does NOT include everything (e.g. `NET` is bound at ~line 690; `directors` later still — referencing exports early throws TDZ; use `global.__G.x`).
- The MENU gate: sim frozen at load — smoketest calls `NET.uiSolo()` before the first tick loop.
- Possession reassigns `player` — use `units.find(u=>u.isPlayer)` in guest-era tests.
- Guest-mode stretches: wrap host-only calls with `NET.mode="host"; ...; NET.mode="guest"` / restore `"solo"`.
- **gameOver mutes ALL dealDamage/damageBuilding.** Every post-campaign section that stages combat opens with `global.__G.setGameOver(false);` (the v95 section carries one too). A missing guard once failed 25 tests at "0 damage".
- **Never assert team-stock deltas across live ticks** — directors spend and economy drips in the same tick. Direct calls to `economyTick(1.0)` are fine. awardPts multiplies by the Bounty buff — ×1.0 at zero stacks. `u.remote="x"` makes a unit "human" for quests/buffs/awardPts.
- Buff tests must ISOLATE buffs (one id at a time; allies >12u from any Captain's Banner bearer; stub `Math.random=()=>0` for dodge/crit and restore).
- applyLOD tests: position the PLAYER, not the camera, and let the LERP arrive.
- `makeUnit` units lack `u.spread`; guard `(u.spread||0)`. Test units: `bot:{role:"citizen"}` for bot hooks, or `bot:null` + big hp to stand inert.
- Real three@0.128.0 loads; `document` stubbed (CanvasTexture-safe); stub elements cache by id. `grep -c` exits 1 on 0 matches. `localStorage` is undefined in node — game code try/catches it.
- Campaign end-state varies — make post-campaign tests deterministic (call managers directly, force `st.respawnAt=-1`, insta-build pending sites, etc.).
- **When adding a regression test, VERIFY IT BITES** — prefer SELF-CALIBRATING pairs (the v95/v96 sections are built of them: choked-lane-skips vs drained-lane-serves; near-ships-8/8 vs far-ships-≤3; fresh-auth-arms vs stale-auth-refused; same-pulse-holds vs bumped-pulse-swings; facing-adopts vs absent-facing-untouched). A probe that passes with the guard removed is vacuous.
- Fixed-coordinate `validFor` probes can flip when placement rules change. Hardened asserts: charge-hold is ≥2/3 within 16; AI-blacksmith counts forges EVER BUILT; camp packs tolerate campaign attrition.
- **v95 net tests**: unit rows are BINARY — decode with `NET.readSnapRows(s)` (never touch s.units, it's gone). To dodge the every-15th full refresh while measuring deltas/AOI: `if((NET._snapN+1)%15===0)NET._snapN++;`. Reset the delta cache with `NET._lastRow=null` (re-inits _lastStruct and _lastBld too). Fake remotes for driveRemote tests need no `inputAt` (absent = never stale); FEED `inputAt` only to test staleness. Craft doctored snaps by readSnapRows → tweak row → `s.ub=NET.packRows(rows); s.q=NET.lastQ+1`. To capture the guest's outgoing input packet: stub `NET.conn={open:true,send:capture}`, `NET.fast=null`, force `NET.inputT=1`, run one `NET.guestFrame(0.001)`, restore.
- **v89 legacy rally states**: tests (and old saves) set `v.rally=true` with NO `v.rallyBy` — toggleRallyFor treats ownerless rallies as belonging to the horn-blower (`mine = v.rally&&(v.rallyBy===u||!v.rallyBy)`); orderCharge accepts `!v.rallyBy` too. Don't "simplify" that away or the v80 charge test breaks.
